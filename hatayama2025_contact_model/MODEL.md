# 模型说明

## 1. 来源与目标

模型依据 Hatayama et al., *ACS Applied Electronic Materials* 7, 2650-2659 (2025), DOI: 10.1021/acsaelm.5c00292。目标是用最少的准静态方程复现以下趋势：

1. Hf、W、Pt 电极对应的 `V_on`、`V_th` 和 `V_hold` 依次降低；
2. 深亚阈值 PF 陷阱参数不随电极改变；
3. 薄膜变薄后两侧耗尽区重叠；
4. 25 nm GeTe6/Pt 的有效势垒过低，阈值开关消失。

## 2. 论文方程

耗尽近似：

`V_in = q N_d W_d^2 / (2 epsilon_s) + const`

Poole-Frenkel 电流：

`I_PF = A exp[-(q Phi - q V Delta_z/(2 u_a))/(k_B T)]`

冲击电离与倍增：

`alpha = B exp[-E_i/(q lambda E)]`

`M = I/I_PF = exp(alpha u_a)`

程序使用电子伏特和伏特表达能量，因此指数中的电荷 `q` 约去。`V_on` 定义为 `M >= 1.01` 的首次交点；工程化 `V_th` 定义为 `M >= 1.50` 的首次交点。

## 3. 接触—体区自洽模型

100 nm 时直接采用论文图 3 的 `V_in`、`W_d`。当 `u_a < 2 W_d` 时，两侧耗尽层重叠：

`overlap = max(0, 1 - u_a/(2 W_d))`

`V_in,eff = V_in (1 - overlap)`

接触的零偏置供应电流由同一个非理想注入方程确定：

`I_s = I_s0 exp[-V_in,eff/(n_i k_B T)]`

正偏接触采用非理想肖特基二极管关系：

`I = I_s {exp[V_f/(n_f k_B T)] - 1}`

反偏接触采用像力势垒降低。用 `gamma_s` 表示局部场增强后：

`Delta_phi_eff = gamma_s sqrt[q V_r/(4 pi epsilon_s W_d)]`

`I = I_s {exp[Delta_phi_eff/(k_B T)] - 1}`

对每个体区电压 `V_bulk`，程序先计算 `I_PF M`，再反算产生相同电流所需的 `V_f` 和 `V_r`，最终满足：

`V_source = V_f(I) + V_bulk(I) + V_r(I)`

因此接触压降真正反馈到 PF 体区电场，三种电极在整个可测亚阈值区均可出现差异；冲击电离只使用自洽求得的体区电场 `E_bulk = V_bulk/u_a`。

当 `V_in,eff < 0.09 V` 时，模型判定势垒不足以在冲击电离前保持低电流，改用泄漏欧姆支路表示 Non-OTS 状态。

## 5. 重要限制

- 论文没有给出全部数值参数，当前结果不是原始曲线的逐点拟合。
- `V_th` 的倍增阈值和 ON 支路是工程定义，不是论文给出的新微观方程。
- 电压分配满足零维电流连续关系，但不是空间分辨 Poisson 方程的自洽解。
- 肖特基接触参数用于复现共同趋势，没有对论文三条曲线进行逐点数字化拟合。
- 模型只做正向准静态扫描，没有迟滞、载流子能量动态或统计涨落。
